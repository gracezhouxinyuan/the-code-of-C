# The Code of C | C语言编程实践

![Language](https://img.shields.io/badge/Language-C-blue)

## 📋 项目简介

本仓库是学习 C 语言过程中积累的编程代码集合，包含：

- **基础算法实现**：排序、递归、数学运算等
- **经典编程问题**：三角形判断、阶乘计算、最大公约数等
- **数据结构操作**：数组、字符串处理
- **控制流程练习**：循环、条件判断、函数设计
- **综合应用案例**：学生管理、密码验证、ISBN校验等
